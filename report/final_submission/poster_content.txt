POSTER TITLE
IELTS Mock Examiner: AI-Assisted IELTS Writing and Speaking Practice Platform

AUTHORS
Azlarkhon Khasakhojaev (220263)
Javlonbek Rustamov (220237)
Central Asian University, Department of Computer Science

PROBLEM
IELTS learners need repeated writing and speaking practice, but access to fast and structured feedback is limited. Existing preparation workflows are often fragmented and do not provide one integrated system for both modules.

OBJECTIVES
- Build a full-stack web platform for IELTS Writing and Speaking practice.
- Provide AI-assisted writing evaluation.
- Provide interactive speaking workflow using speech processing components.
- Ensure reproducible local deployment through containerization.

SYSTEM ARCHITECTURE
- Frontend: React + Vite + TypeScript + Tailwind/shadcn.
- Backend: Django + Django REST Framework + Channels.
- API modules: core, authentication, writing, speaking.
- Data/runtime: SQLite configuration, media/cache volumes, environment-driven settings.

KEY FEATURES
- User authentication and protected practice workflows.
- Writing submission and evaluation flow through Gemini-configured AI service.
- Speaking pipeline with VAD-based segmentation, STT configuration, and TTS configuration.
- Dedicated frontend pages for writing, speaking, dashboard, and admin configuration.

TECH STACK
- Python, Django, DRF, Channels
- React, Vite, TypeScript, Tailwind CSS
- Gemini integration, Faster-Whisper model path configuration, Kokoro model path configuration
- Docker, Docker Compose

CURRENT RESULTS / VALIDATION
- Backend and frontend run as integrated services via Docker Compose.
- Backend health endpoint is used for service readiness checks.
- Functional coverage includes writing and speaking module flows with configurable AI/runtime parameters.

CONCLUSION
IELTS Mock Examiner establishes a practical and modular technical foundation for AI-assisted IELTS preparation. The system is operational for integrated writing and speaking practice.

FUTURE WORK
- Quantitative benchmarking for response quality and latency.
- User acceptance testing with IELTS learners.
- Enhanced analytics and adaptive feedback strategies.
